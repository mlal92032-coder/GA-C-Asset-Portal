KEY PRINCIPLES
================================================================================

1. CLEAR SEPARATION
   Each component has a unique z-index range
   No ambiguity about what's on top

2. CONSISTENT STACKING
   Same type of element → same z-index
   All modals: z-[9998]/z-[10000]
   All toasts: z-[99999]

3. LOGICAL GROUPS
   Related elements bundled together
   Modal overlay + content = one unit
   Search = one layer

4. LARGE GAPS
   Lots of space between layers
   Room for future additions
   No accidental conflicts

5. DOCUMENTATION
   Every z-index documented
   Easy to understand
   Easy to maintain
