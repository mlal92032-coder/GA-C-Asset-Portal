## 🚀 **How to Use**

### **Step 1: Filter Assets**
1. Go to Settings → **QR Code** tab
2. Select filters:
   - **Category** - Choose asset type
   - **Status** - In Use / In Store
   - **Location** - Where asset is
3. See filtered results instantly

### **Step 2: Select Assets**
**Option A - Select Individual:**
- Click checkbox on each asset card
- OR click "📥 Download" on individual card

**Option B - Select Multiple:**
- Click **"✓ Select All"** to select all filtered
- Click **"✕ Clear All"** to deselect all
- See counter: "5 selected of 12"

### **Step 3: Download/Print**

**Option 1 - Download Single:**
1. Find asset in grid
2. Click **"📥 Download"** button
3. Get: `qr-AST-00001.html`
4. Open in browser and print

**Option 2 - Bulk Download:**
1. Select multiple assets
2. Click **"📥 Download [N] QRs"**
3. Get: `qr-codes-2026-07-09.html`
4. Open and print all at once

**Option 3 - Print Directly:**
1. Select assets
2. Click **"🖨️ Print [N] Labels"**
3. Auto-opens print preview
4. Ready to print labels

## 🔧 **Technical Details**

### **State Management:**
- `filterCategory` - Selected category
- `filterStatus` - Selected status
- `filterLocation` - Selected location
- `selectedAssets` - Array of selected asset IDs
- `filteredAssets` - Computed filtered list

### **Functions:**
- `toggleAsset()` - Add/remove from selection
- `handleSelectAll()` - Select all filtered
- `handleDownloadSingleQR()` - Download individual
- `handlePrintQRs()` - Print selected
